核心判断

BrowserAct 的差异点不是普通无头 Chrome 封装，而是围绕 Agent 被网站拦截的问题设计了三层突破体系。 它还提供 stealth、chrome、chrome-direct 三种浏览器模式，并通过 Skill Forge 把跑通的网站流程沉淀为可复用 Skill。

三层突破体系

stealth 反检测浏览器 指纹伪装、WebDriver 隐身、请求头一致性，适合有访问限制的网站。 环境层
动态代理 代理轮换配合反检测浏览器，用于 Product Hunt、YouTube 等高频采集。 环境层
stealth-extract 像高级 WebFetch 一样启动反检测浏览器，等待 JavaScript 渲染后提取干净内容。 执行层
solve-captcha 自动解决常见验证码，让 Agent 在无人值守场景里继续执行。 执行层
remote-assist 生成远程链接，让 Human 在手机或其他设备扫码登录、短信验证，然后 Agent 继续原会话。 人机协作层
Skill Forge 把跑通的网站操作流程生成可复用 Skill，例如知乎搜索、小红书提取、微信文章检索。 人机协作层

三种浏览器模式怎么选

stealth 模式

反检测浏览器 + 指纹伪装 + 代理轮换，适合批量采集、匿名访问、竞品监控。

chrome 模式

把本地 Chrome Profile 导入独立环境，复用已有登录态但避免污染当前浏览器。

chrome-direct 模式

直接控制当前正在运行的 Chrome，零配置，天然带登录态和插件。
